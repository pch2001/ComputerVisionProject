# 4차 업무 기획서 · 클래시 오브 클랜 스크린샷 기반 공격 판단 도구

## 목표와 판단 기준

상대 마을 스크린샷에서 탐지한 건물의 총개수와 사용자가 입력한 내 전투 병력 수를 비교한다. 내 병력 수가 탐지 건물 수보다 많으면 공격 조건 충족을 표시한다. 내 병력 수가 같거나 더 적으면 공격 보류를 표시한다.

## 사용 흐름

1. 스크린샷을 입력하면 YOLOv8n이 건물을 탐지하고 OpenCV가 결과 이미지를 저장한다.
2. 분석이 끝나면 내 전투 병력의 총인원을 입력한다.
3. 상대 전력으로 탐지된 건물의 종류별 개수와 총개수를 표시한다.
4. 상대 건물 총개수와 내 병력 수를 비교해 공격 조건 충족 또는 공격 보류를 표시한다.

판단에는 모델이 탐지한 상자 수를 사용한다. 3차 테스트의 평균 재현율은 34.9%였으므로 탐지 수는 실제 전체 건물 수와 다를 수 있다.

## 개발 순서와 일정

| 단계 | 작업일 초안 | 작업 및 완료 기준 |
|---|---|---|
| 1. 기획 | 1일차 | 총개수 비교 규칙과 입출력을 정한다. |
| 2. 개발 | 2~3일차 | Python으로 개수 비교를 구현하고 Git으로 변경을 관리한다. pytest로 초과·동일·미만과 잘못된 입력을 검증한다. |
| 3. 통합 테스트 | 4일차 | 이미지 입력부터 YOLOv8n 탐지, OpenCV 결과 저장, 병력 수 입력, 판단 표시까지 확인한다. |
| 4. 발표와 제출 | 통합 테스트 후 1일 | 실행 파일과 사용 안내, Git 저장소 링크, 4장 이내 PPT를 준비한다. |
