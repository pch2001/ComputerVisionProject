# 클래시 오브 클랜 스크린샷 분석 도구

상대 마을의 스크린샷에서 건물을 탐지하고, 내 병력 수가 탐지 건물 수보다 많은지 판단한다. 프로그램은 결과를 터미널에 표시하고 탐지 상자가 그려진 이미지를 저장한다.

## 실행 준비

- Windows에서 Python과 Ultralytics, OpenCV, NumPy를 사용할 수 있어야 한다. 단위 테스트에는 pytest가 필요하다.
- 실행 파일과 Python 파일은 `D:\AI\Comment\ComputerVisionProject\4차 업무`에 있다.
- 기본 모델은 같은 프로젝트의 `3차 업무\runs\train\exp-4\weights\best.pt`다. 다른 위치에서 실행할 때는 아래 명령의 모델 경로를 지정한다.

## 실행과 시연

1. `스크린샷_분석_실행.bat`를 더블클릭한다.
2. 열린 창에 마을 스크린샷 파일을 끌어다 놓고 Enter를 누른다.
3. 분석 완료 메시지가 나오면 내 전투 병력 수를 정수로 입력한다.
4. 탐지된 상대 건물의 총개수와 종류별 개수, 공격 판단을 확인한다. 탐지 결과는 실행 파일과 같은 폴더의 `detection_result.png`에 저장된다. 같은 이름의 기존 결과는 다음 실행에서 덮어쓴다.

PowerShell에서 실행하는 방법도 있다. 이미지와 모델 경로는 실제 위치에 맞춘다.

```powershell
cd "D:\AI\Comment\ComputerVisionProject\4차 업무"
python .\analyze_screenshot.py "C:\이미지\마을.png" --model "D:\AI\Comment\ComputerVisionProject\3차 업무\runs\train\exp-4\weights\best.pt"
```

## 확인한 결과

Windows에서 검증 이미지 한 장을 사용해 탐지 건물 33개를 얻었다. 아래 세 경우에 탐지 결과 이미지 저장과 판단 출력을 확인했다.

| 내 병력 | 상대 탐지 건물 | 실제 출력 |
|---:|---:|---|
| 40명 | 33개 | 공격 조건 충족 |
| 33명 | 33개 | 공격 보류 |
| 30명 | 33개 | 공격 보류 |

비교 함수의 단위 테스트 7개도 통과했다. 프로젝트의 4차 업무 폴더에서 아래 명령으로 다시 실행할 수 있다.

```powershell
python -m pytest -q .\test_attack_decision.py
```

판단 기준은 탐지 건물 수와 병력 수의 대소 관계다. 탐지 누락과 오탐으로 인해 건물 수가 실제와 다를 수 있으며, 판단 결과는 게임 승률을 나타내지 않는다.
